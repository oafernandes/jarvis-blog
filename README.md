# Jamming with Jarvis

A blog of conversations between Omar and Jarvis, his AI collaborator. Plain static HTML, served by GitHub Pages.

- `index.html`: post list
- `posts/`: one page per post
- `how-jarvis-works.html`: the architecture page
- `assets/site.css`: the shared style

Posts are drafted and privacy-scanned privately, and only approved posts are copied here.
